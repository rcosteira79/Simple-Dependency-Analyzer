How should the side explorer panel be organised?

This sits next to the graph and lets you find and focus modules.

A

Grouped by type

Modules grouped into categories (App, Feature, Core, Data…) inferred from their name or applied plugins. Familiar for Android devs.

Module Explorer
App (1)
📦 :app app
Feature (3)
📦 :feature-auth feat
📦 :feature-home feat
📦 :feature-profile feat
Core (2)
📦 :core-ui core
📦 :core-network core
Data (1)
📦 :data-user data
B

Mirroring Gradle path hierarchy

Reflects the actual directory/path structure of your Gradle project. Nested modules appear as children. Matches what you see in settings.gradle.

Module Explorer
▾ 📁 :app
▾ 📁 :feature
📦 :feature:auth
📦 :feature:home
📦 :feature:profile
▾ 📁 :core
📦 :core:ui
📦 :core:network
▾ 📁 :data
📦 :data:user
C

Both — switch between views

A toggle at the top of the panel lets you flip between the type-grouped view and the path-hierarchy view. Flexible, but slightly more surface area to build.
